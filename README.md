# سرویسیار

**سرویسیار** یک وب اپلیکیشن فارسی، راست‌چین و ماژولار برای مدیریت خدمات پس از فروش و تعمیرات لوازم خانگی است.

هدف محصول این است که به تعمیرکاران، تیم‌های خدماتی و نمایندگی‌ها فروخته شود و با کد فعال‌سازی و ماژول‌های قابل انتخاب کار کند.

## امکانات MVP

- ورود و ثبت‌نام
- ساخت کسب‌وکار
- فعال‌سازی با کد لایسنس
- مدیریت مشتریان
- مدیریت آدرس مشتری
- مدیریت دستگاه مشتری
- ثبت درخواست تعمیر
- مدیریت وضعیت درخواست
- مدیریت تکنسین‌ها
- ثبت گزارش تعمیر
- صدور فاکتور
- چاپ فاکتور فارسی
- پنل مدیر کل
- ساخت و مدیریت لایسنس
- مدیریت ماژول‌های فعال هر کسب‌وکار

## تکنولوژی‌ها

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- GitHub Actions
- Vercel-ready

## مسیرهای اصلی

