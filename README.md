# سرویسیار

**سرویسیار** یک وب اپلیکیشن فارسی و ماژولار برای مدیریت خدمات پس از فروش و تعمیرات لوازم خانگی است.

## امکانات پایه MVP

- مدیریت کاربران
- ساخت کسب‌وکار یا Tenant
- مدیریت پلن‌ها
- مدیریت ماژول‌ها
- لایسنس و کد فعال‌سازی
- مدیریت مشتریان
- مدیریت دستگاه‌های مشتری
- ثبت درخواست تعمیر
- ارجاع به تکنسین
- گزارش تعمیر
- فاکتور ساده

## تکنولوژی‌ها

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Docker

## اجرای پروژه روی سیستم توسعه

ابتدا فایل `.env.example` را به `.env` تبدیل کنید و مقدار `DATABASE_URL` را تنظیم کنید.

سپس:

```bash
npm install
docker compose up -d
npx prisma migrate dev --name init
npm run db:seed
npm run dev
```
