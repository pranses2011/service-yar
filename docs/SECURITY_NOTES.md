# نکات امنیتی سرویسیار

## موارد انجام‌شده

- رمز کاربران با bcrypt هش می‌شود.
- داده‌ها با tenantId جدا می‌شوند.
- نقش‌های کاربری تعریف شده‌اند.
- ماژول‌ها بر اساس Tenant کنترل می‌شوند.
- عملیات مهم در AuditLog ثبت می‌شود.

## موارد لازم قبل از فروش جدی

- Session امن‌تر
- Rate Limit فرم ورود
- تغییر رمز
- بازیابی رمز
- OTP پیامکی
- بررسی وضعیت License در همه عملیات
- بکاپ دیتابیس
- مانیتورینگ خطا
